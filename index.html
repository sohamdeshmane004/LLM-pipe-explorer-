The Trinity of Attention: Q, K, V

In traditional computing, an index is static. In the Transformer's attention chamber, every token creates three specialized vectors:

Q — The Query "What am I seeking?"

The question or requirement broadcast by the token. For example, when the token is "it", its query asks: "Which sacred noun in this sentence do I replace?"

K — The Key "What do I offer?"

The identification label each token publishes to the realm. The token "grimoire" holds a key saying: "I am a masculine/neuter singular mystical book."

V — The Value "What wisdom do I impart?"

The actual contextual meaning transferred if the dot product of Query and Key yields a high affinity score.

Attention(Q, K, V) = softmax( (Q · Kᵀ) / √dₖ ) · V

Dividing by √dₖ prevents dot-products from growing explosively in high dimensions, preventing the softmax function from suffering vanishing gradients.

How Attention Solves Ambiguity

Notice in sentence 1 how "it" heavily attends to "grimoire" instead of "altar" when the modifier is "sacred". If we changed the sentence to "because it was heavy", the attention weights would shift toward the altar. This dynamic shifting is true semantic comprehension!

Component Details

Multi-Head Self-Attention

Magical Purpose

The Great Council of Runes. Instead of looking at context from a single viewpoint, multiple attention heads inspect the sentence simultaneously: one head tracks grammar, another tracks pronoun references, and another tracks emotional tone.

Technical Operation

Projects the incoming tensor into Q, K, and V spaces across h heads, computes scaled dot-product attention in parallel for each head, concatenates the resulting matrices, and projects them back with an output weight matrix W_O.

Why Residual Connections Are Vital

The residual line acts like an unbroken enchanted lifeline. Without it, gradients would vanish exponentially across 96 layers. It allows original token identities to flow undisturbed while layers apply delicate additive refinements.
